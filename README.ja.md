# 造船所ソルバーラボ

[English README](README.md)

## 一言でいうと

公式データ公開前から証拠を積みたい最適化コンテスト参加者のために、造船所パズルを「解く・検証する・提出パッケージ化する」再現可能なループにするプロジェクトです。

## 誰のためのものか

Optimization Grand Challenge 2026 に挑戦する参加者、またはソルバー、チェッカー、ベンチマーク、レポート、提出zipを一体で管理したい開発者のためのワークベンチです。

## 何が困りごとか

最適化コンテストでは、良いアイデアだけでは足りません。ソルバーが動いても、公式チェッカーで落ちる、出力が再現できない、提出パッケージの形が違う、レポートが残らない、というだけで信頼を失います。

## どう解決するか

- サンプルインスタンスを読み込みます。
- ブロック配置を生成します。
- 境界と重なりを検証します。
- ベンチマークを走らせます。
- 公開OGC例を読み込むスモークテストを持ちます。
- 公式チェッカーを通す確認を持ちます。
- 候補 `myalgorithm.py` を含む提出zipを生成します。
- ダッシュボード、スクリーンショット、デモ動画、レポートを残します。

## はじめての使い方

1. 右上の `日本語` を押します。
2. まず上のスコアカードで、配置数、カバー率、ベンチマーク回数を見ます。
3. 左側の説明で、どのアルゴリズムが動いているかを確認します。
4. 中央の `ヤード配置` で、ブロックがどこに置かれたかを見ます。
5. 下の `解テーブル` で、各ブロックの位置、サイズ、回転を確認します。
6. 技術的な確認をする時は、`npm run verify` でソルバー、チェッカー、提出zip、動画、日本語UIをまとめて検証します。

## 画面の見方

- この画面は「解く流れが再現できる」ことを見せる画面です。
- `最高実行` は、サンプルデータで一番よかった実行結果です。
- `公式チェッカー確認` は、公式形式との接続確認です。
- `公式パッケージ` は、提出zipを作れることを示します。
- まだ公式リーダーボード順位や最終成績を主張するものではありません。

## 日本語対応

画面右上の `日本語` ボタンで、日本語UIに切り替えられます。英語の公式コンテスト向けの説明を維持しながら、日本語でも「何を証明しているか」が読めるようにしています。

## 主張の境界

このリポジトリは公式リーダーボード成績を主張しません。公式訓練データ、最終成績、提出完了も主張しません。現在の価値は、公式データ公開前に再現可能な開発ループを用意していることです。

## 検証

```bash
npm run verify
```

検証では、公式例投影、公式チェッカー確認、候補パッケージ、no-secrets、日本語UI切替、デモ動画資産をまとめて確認します。
